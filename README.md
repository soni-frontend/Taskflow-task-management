# TaskFlow – Task Management System

A modern and responsive task management application designed to help users organize their daily tasks, track progress, and manage their work efficiently.

## 🌐 Live Demo

**Live Website:** https://taskflow-task-management-sandy.vercel.app/

## 📌 About the Project

TaskFlow is a web-based task management application built to make everyday task planning easier and more organized.

Users can create and manage tasks, set deadlines, track completion status, and monitor their productivity through a clean dashboard.

The project includes a frontend, backend API, and database integration.

## ✨ Features

* User Registration and Login
* Task Creation and Management
* Edit and Delete Tasks
* Task Completion Tracking
* Task Priority Management
* Task Categories
* Due Dates and Time
* Dashboard with Task Statistics
* Search, Filter, and Sort Tasks
* Dark Mode and Light Mode
* Responsive User Interface
* MongoDB Database Integration
* Live Deployment

## ⚙️ How to Run the Project Locally

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual project repository URL.

### 2. Install Frontend Dependencies

Open the frontend project folder in your terminal and run:

```bash
npm install
```

### 3. Configure the Backend

Navigate to the backend folder:

```bash
cd backend
```

Install the backend dependencies:

```bash
npm install
```

Create a `.env` file in the backend folder and configure the required environment variables, including your MongoDB connection string and server port.

Do not upload your database credentials or other secrets to GitHub.

### 4. Start the Backend

Run:

```bash
node server.js
```

### 5. Start the Frontend

Open another terminal in the frontend project directory and run:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

**Note:** For local development, configure the frontend API URL to point to your local backend. For production, use the deployed backend URL.
